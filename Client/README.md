# Client

Временный статический личный кабинет: вход, профиль, статистика, достижения,
история рейсов и кнопка «Играть». Чистые HTML, CSS и ES-модуль без сборки.

Отдельного dev-сервера нет: страницу раздаёт `../Server` (`npm run dev` в
`Server/`, затем <http://localhost:3000/>). Все запросы идут на тот же origin в
`/api/*`.

## Проверка

```powershell
npm ci --include=dev
npm run verify
```
