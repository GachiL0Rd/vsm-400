# Правила работы с модулем Client

`Client/` — временный статический кабинет. Без сборщика, фреймворков и
runtime-зависимостей: `index.html`, `styles.css`, `app.js`. Единственная
dev-зависимость — Biome.

- API описан в `../Server/README.md`; клиент ходит на относительные `/api/*`.
- Токен хранится в `localStorage` под ключом `vsm.token`.
- Вёрстка mobile-first, классы по BEM.
- Для визуальных изменений запустите `Server/` и проверьте страницу в браузере
  на узкой и широкой ширине.
- После изменения: `npm run verify`.
