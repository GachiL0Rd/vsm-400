# Документация репозитория

Этот каталог содержит только кросс-проектные материалы. Реализация и
нормативные требования каждого модуля живут рядом с модулем.

| Источник | Роль | Следующий документ |
| --- | --- | --- |
| [`../Game/docs/user/`](../Game/docs/user/README.md) | Нормативные product, architecture и protocol требования Game | [`../Game/docs/agent/`](../Game/docs/agent/README.md) для рабочих guide |
| [`agent/`](agent/README.md) | Общий workflow и необязательные инструменты | Локальный `AGENTS.md` затронутого модуля |
| [`user/`](user/README.md) | Исследовательская база, общая для проекта | Game requirements, если исследование применимо |
| [`backlog/`](backlog/README.md) | История, не являющаяся текущим требованием | Только для справки |

Связь материалов односторонняя: исследование может уточнять требования Game;
требования задают реализацию; рабочие guide помогают выполнить текущую задачу,
но не переопределяют требования. Архив не является источником требований.
