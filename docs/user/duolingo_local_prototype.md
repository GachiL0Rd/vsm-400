# Локальный учебный прототип «Смена»

Текущее направление — короткие уроки по работе проводника в интерфейсе
учебного маршрута. Прототип вдохновлён понятной последовательностью уроков,
мгновенной обратной связью и повторением из Duolingo; фирменные материалы
Duolingo не используются. Ранее описанная непрерывная пространственная смена
не входит в этот срез.

## Что уже можно пройти

- Путь из трёх последовательно открываемых уроков: свободный проход, неисправная
  кнопка вызова, помощь пассажиру с нарушением зрения.
- В каждом уроке — два диалога с выбором действия. Выбор меняет две локальные
  шкалы: безопасность и лояльность пассажира. После каждого действия появляется
  объяснение последствия, а в конце — разбор обоих решений.
- В одном из эпизодов промедление имеет отдельное последствие по таймеру.
- После первого завершения урока начисляется 20 XP. Урок можно повторить без
  ограничения; повторное завершение не начисляет XP. Прогресс и XP сохраняются
  только в `localStorage` текущего браузера.
- Сцена вагона рисуется средствами Phaser. Генератор сценариев выбирает местные
  варианты вагона, места и начальной реплики внутри заранее подготовленных
  ветвящихся сценариев. Сценарии полностью работают без сервера и ИИ.

## Границы и источники

Реализован учебный прототип, а не аттестационная система: баллы и последствия
в ответах — игровые оценки, их нужно отдельно согласовать с экспертами.
Отправки результатов, входа по учётной записи, лидерборда и серверной части
нет. Используемый стек ограничен Vite, TypeScript и Phaser 4.

Темы уроков адаптированы из материалов организатора: «Ситуации на борту»
(№ 14, 16, 23), СТО РЖД 03.013 и СТО РЖД 03.014. Первоисточники остаются вне
репозитория; ссылки на конкретные темы показываются в разборе урока.

Запуск и проверка описаны в [`Game/README.md`](../../Game/README.md).
