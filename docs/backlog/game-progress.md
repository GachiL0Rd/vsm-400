# Прогресс модуля Game

> Архивный журнал ранней инициализации. После перехода к командному workflow
> файл не обновляется и не является источником актуальных требований.

`Game/` — модуль браузерной игры внутри более крупного проекта. Родительский репозиторий может также содержать веб-оболочку, сервер и инструменты генерации ассетов; их устройство этим файлом не определяется.

## Текущее состояние

- Стек: Phaser **4.2.1**, TypeScript **5.9.3**, Vite **8.3.1**.
- Целевая версия Node.js: **24.21.0**.
- Установка: `npm ci`.
- Локальный запуск: `npm run dev`.
- Основная проверка: `npm run verify`.
- `index.html` служит локальной dev-оболочкой, а не финальной страницей продукта.
- Стартовая сцена в `src/main.ts` показывает `Phaser ready`; игрового контента пока нет.
- `node_modules/` и `dist/` не входят в Git.

## Открытые вопросы

- Каким способом модуль игры будет встроен в основную веб-страницу: отдельный статический route/iframe или прямой JS mount/import.
- Конкретная файловая структура `src/` будет сформирована после появления первых реальных механик, а не заранее.
- Quality tooling (Biome/Vitest/Knip) подключается после появления кода, который имеет смысл форматировать/тестировать/анализировать.
