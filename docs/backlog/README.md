# Backlog и архив

Здесь хранятся старые журналы прогресса, устаревшие документы и материалы,
которые больше не должны засорять актуальное пространство документации.

Содержимое каталога не является действующим требованием. Актуальная
пользовательская документация находится в `../user/`, инструкции для агентов —
в `../agent/`.
