# Кросс-проектный backlog и архив

Здесь хранятся только кросс-проектные старые журналы и материалы. История
конкретного модуля хранится в его собственном `docs/backlog/`: для Game —
[`../../Game/docs/backlog/`](../../Game/docs/backlog/README.md).

Содержимое каталога не является действующим требованием. Кросс-проектная
исследовательская база находится в `../user/`, общий workflow — в `../agent/`.
