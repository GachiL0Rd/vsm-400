# Необязательные инструменты агента

Для сборки проекта нужны только Git, Node.js и npm. Инструменты ниже не
обязательны для участников и CI. Файл можно удалить без изменения проекта или
его основных команд.

## just

`just` читает `justfile` конкретного модуля и предоставляет короткие имена для
его обычных команд. Это меню команд, а не отдельная система сборки. Точные
рецепты должны документироваться внутри владеющего ими модуля.

## Pueue

Pueue запускает и отслеживает длительные процессы. Агент может передать ему
сборку, тесты или dev-сервер, чтобы процесс имел идентификатор, журнал и мог
быть безопасно остановлен. Обычный участник может запускать те же команды
напрямую.

Идентификаторы групп и правила временных серверов задаются в документации
конкретного модуля, чтобы процессы разных подпроектов не смешивались.

## fd

`fd` ускоряет поиск файлов и каталогов. Он удобен для обнаружения модулей,
`AGENTS.md`, конфигураций и тестов. Стандартные средства PowerShell остаются
допустимой заменой.

## rg

`rg` (ripgrep) быстро ищет буквальный текст и регулярные выражения по
репозиторию с учётом ignore-файлов. Он удобен для поиска ссылок, команд,
символов и незавершённых маркеров.

## procs

`procs` показывает запущенные процессы, их командные строки и связи
родительских и дочерних процессов в более удобном виде, чем базовые
средства. Он полезен перед повторным запуском или остановкой dev-сервера:
агент может убедиться, что не создаёт дублирующий процесс. В PowerShell его можно
заменить `Get-Process` или `Get-CimInstance Win32_Process`.
