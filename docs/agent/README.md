# Кросс-проектная документация для агентов

  модулями.

тесты и текущие implementation guide находятся у самого модуля: для Game это
[`../../Game/AGENTS.md`](../../Game/AGENTS.md) и
[`../../Game/docs/agent/`](../../Game/docs/agent/README.md).
