# Необязательные изображения клиента

Игра запускается без файлов в этих каталогах: фон и персонажи рисуются простыми фигурами.

Для замены плейсхолдеров положите файлы в следующие места:

- `characters/<appearanceId>.png` — PNG персонажа с прозрачным фоном. Имя файла должно совпадать с `appearanceId` из публичного состояния сервера, например `character.conductor.default.png` или `passenger.demo-1.png`. Если точного файла нет, используется `characters/player.png` или `characters/passenger.png`; затем — фигура.
- `map/train.tmj` — экспорт карты Tiled в JSON. Формат `.tmx` Phaser напрямую здесь не загружает.
- `map/<tilesetName>.png` — PNG каждого тайлсета. Имя файла без расширения должно совпадать с именем тайлсета внутри `.tmj`. Для этой заготовки тайлсеты должны быть доступны в экспортированном JSON, а не только в внешнем `.tsx`.

Слои Tiled являются **фоном**. Их размещение начинается от левой верхней публичной клетки, полученной в первом snapshot. Клетки, движение и доступные действия по-прежнему задаёт сервер; декоративная карта не меняет игровую сетку. До подключения большой карты серверу понадобится соответствующий ей Level с координатами клеток.
