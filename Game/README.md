# Game

Локальный обучающий прототип на Phaser 4, TypeScript и Vite. Игрок проходит
короткий учебный путь проводника: читает диалог, выбирает действие и видит
последствия для безопасности и лояльности пассажира.

## Требования

- Node.js 22.12.0 или новее; рекомендуемая LTS-major указана в `.nvmrc`;
- npm.

## Запуск

Из каталога `Game/`:

```powershell
npm ci --include=dev
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173/`).
Сервер Vite нужен только для раздачи файлов во время разработки; игрового API,
учётных записей и сетевого сохранения нет. Прогресс трёх уроков и XP хранятся
в `localStorage` браузера.

Сейчас доступны уроки «Свободный проход», «Кнопка не отвечает» и «Помощь в
пути». Каждый состоит из двух решений и разбора. Генератор в
`src/domain/scenarios.ts` собирает локальные варианты из подготовленных
шаблонов (место, вагон и реплики), а не создаёт новые ситуации через ИИ.

Полная проверка:

```powershell
npm run verify
```

Если установлен `just`, доступны эквивалентные сокращения `just setup`,
`just dev` и `just check`. `just` не является обязательной зависимостью.

Перед изменением прочитайте `AGENTS.md` и актуальное описание прототипа в
`../docs/user/duolingo_local_prototype.md`.
