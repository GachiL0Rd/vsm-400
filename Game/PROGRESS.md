# Прогресс проекта vsm-moscow

Этот файл — общий журнал команды и агентов. Добавляйте новые записи в начало раздела «Журнал» и не удаляйте предыдущие. Фиксируйте проверяемый результат, принятые решения и вопросы, которые влияют на следующую работу.

## Инициализация

- Проект находится в `Game/`; в текущем состоянии репозитория это единственный каталог в корне Git.
- Стек: Phaser **4.2.1**, TypeScript **5.9.3**, Vite **8.3.1**. Версии зафиксированы в `package.json` и `package-lock.json`.
- Требуется Node.js `^20.19.0` или `>=22.12.0` и npm.
- Установка: `cd Game` → `npm ci`.
- Локальный запуск: `npm run dev`; сборка: `npm run build`; проверка типов: `npm run typecheck`.
- Стартовая сцена в `src/main.ts` показывает `Phaser ready`. Игрового контента пока нет.
- `node_modules/` и `dist/` не входят в Git. README не используется.
