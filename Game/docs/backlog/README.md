# Backlog и архив Game

Этот каталог содержит устаревшие документы и исторические планы модуля Game.

Содержимое **не является действующим требованием**. Актуальная нормативная документация находится в [`../user/`](../user/README.md), рабочие инструкции — в [`../agent/`](../agent/README.md).

`legacy-agent/` сохраняет документы старого mechanics-playground, zone-based
WebSocket demo и прежнего Phaser-клиента только для исторической справки.
`legacy-user/` содержит ранние game requirements; snapshots
`game-progress.md`, `iteration-07-gap-analysis.md` и
`iteration-07-remaining-work-pre-integration.md` фиксируют состояния до
authoritative integration hardening.
