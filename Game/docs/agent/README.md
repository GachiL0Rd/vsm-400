Этот каталог содержит только актуальные рабочие инструкции для разработки модуля Game.

Перед работой:

1. прочитать [`../user/README.md`](../user/README.md);
2. свериться с [`iteration-07-remaining-work.md`](iteration-07-remaining-work.md);
3. при необходимости использовать [`tools.md`](tools.md).

Исторические документы старого mechanics/demo-клиента перенесены в [`../backlog/legacy-agent/`](../backlog/legacy-agent/) и не должны использоваться как архитектурная спецификация.
