# Клиентский HUD

**Версия документа:** 0.1.0
**Статус:** Draft / текущая оболочка клиента
**Дата редакции:** 2026-09-27

HUD — DOM-слой поверх канвы Phaser. Он показывает публичное состояние и
transient presentation events. Решения симуляции остаются на сервере.

## Оболочка

- Фон страницы `#10222C`. Панели `rgba(16, 34, 44, 0.92)`.
- Текст `#EEF9FF`, шрифт Monocraft (`Game/assets/fonts/Monocraft.woff2`, SIL OFL 1.1).
  В шрифте нет глифа «№», строки HUD его не используют.
- «Задачи» — фаза попытки и прежняя подсказка, панель сворачивается.
- «Скорость времени» — ×1 ×2 ×4, активная скорость с серверных часов.
- Нижний диалог — последняя реплика `speech` или `hint` со стилем `message`,
  плюс кнопки текущего `action-offer`. Формы действий остаются модалками.
- Реплика скрывается примерно через 6 с, пока не открыт offer.
- Низ: «Наблюдения» (реплики, новые сверху, время симуляции мм:сс),
  «События» (уведомления, смены фазы, отказы команд, названия достижений),
  «Действия» (подписи текущего offer или подсказка, куда нажать).
  Разбиение колонок — клиентская интерпретация макета, её можно заменить.
- «Предметы» — один слот. `item.extinguisher` берёт `assets/ui/extinguisher.png`,
  журнал — локальный знак, пустые руки — «В руках: пусто».
- Слева внизу постоянная подсказка хода. На таче она видна без hover.

## События

`PresentationStore` только раскладывает сообщения. Повтор `sequence` в одной
попытке отбрасывается. Новый snapshot / другая попытка очищают журнал, тосты
и диалог.

| Сообщение | Куда |
| --- | --- |
| `speech` visible | диалог и «Наблюдения»; спикер «Проводник» или «Пассажир» |
| `speech` hidden | закрыть речевой диалог |
| `notification` | тост и «События» |
| `achievement-unlocked` | отдельный тост и строка в «События» |
| `hint` `message` | диалог |
| `hint` `toast` | тост |
| `hint` `highlight`, `effect` | не показывать, только журнал клиента |
| `command-result` rejected | «События» и короткий тост; `stale-revision` молча, затем resync |
| `error` | «События», короткий тост и состояние связи; текст сервера |
| `session-state` `paused` | «Связь потеряна, игра на паузе…» |
| `session-state` `finishing` | «Подводим итоги рейса…» |
| `session-state` `finished` | карточка, «Посмотреть результат», автопереход 5 с, его можно отменить |
| `session-state` `aborted` | «Попытка прервана» |

Тосты: не больше трёх на экране, остальные ждут, каждый живёт около 4 с.
Наведение мышью ставит таймер на паузу. Неизвестный id достижения —
«Достижение получено». Известные: `documents-perfect`, `fast-fire-response`,
`safe-emergency-stop`, `all-service-requests-resolved`, `clean-predeparture`.

Коды отказа: `action-rejected` «Действие сейчас недоступно.», `invalid-target`
«Эта цель недоступна.», `unsupported-command` «Команда не поддерживается.».
Прочие коды показывают текст сервера. `invalid-target` в protocol v1 пока не
входит в enum `command-result`, но клиент уже умеет его подпись.

## Телефон

Горизонтальный режим (`max-height: 500px` и `orientation: landscape`): «Задачи»
сворачиваются в кнопку, низ — одна полоса высотой 48 px с вкладками и слотом
предмета, диалог над полосой примерно на 2 строки (выше, если открыт offer).
Портрет уже 900 px показывает
«Поверните телефон горизонтально». Канва не скроллит страницу
(`touch-action: none`, `overscroll-behavior: none`, `viewport-fit=cover`).

Короткий landscape оставляет канву на весь экран. Узкий портрет резервирует
полосы под HUD; широкий экран и короткий landscape рисуют мир на всю канву.

Канва в пикселях устройства: Scale `NONE`, backing store × `devicePixelRatio`,
zoom менеджера `1 / devicePixelRatio`. Камера берёт наибольший целый масштаб,
при котором ряды карты 5–12 (сиденья, проход) помещаются по высоте, и держит
этот пояс по вертикали. По горизонтали следит за проводником.

Кнопка «?» в полосе времени открывает клиентский оверлей первого запуска
(ключ `localStorage` `vsm.guide.seen`). Пять шагов: цель смены, клик/тап,
«Задачи» / «Наблюдения» / «События» / «Предметы», скорость ×1 ×2 ×4, журнал
приёмки на перроне. «Далее», «Назад», «Понятно, начать», Enter и Esc.
Оверлей не ставит сервер на паузу. Серверные `hint` по-прежнему идут в диалог
или тост.

## Открытый вопрос

У публичной сущности есть только `appearanceId`. Имени пассажира в protocol v1
нет, поэтому реплика подписана «Пассажир», пока контракт не отдаст имя.
