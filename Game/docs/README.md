# Документация модуля Game

Документация Game разделена по назначению и приоритету:

- [`user/`](user/README.md) — действующие product/release/baseline, архитектурные и implementation-требования. Это нормативный источник для текущей разработки игры; текущий release scope и целевой baseline различаются явно.
- [`agent/`](agent/README.md) — рабочие инструкции для агентов и актуальные списки оставшейся реализации. Эти документы не заменяют требования из `user/`.
- [`backlog/`](backlog/README.md) — устаревшие планы, описания удалённого demo и прочий исторический контекст. Содержимое не является действующим требованием.

При конфликте использовать `user/`, затем актуальные инструкции из `agent/`. `backlog/` служит только справочным архивом.

Связи с документами верхнего уровня:

- [`../../docs/README.md`](../../docs/README.md) — кросс-проектная карта;
- [`../../docs/user/`](../../docs/user/README.md) — исследовательская база,
  которая может уточнять требования, но не заменяет `user/`;
- [`../../docs/agent/`](../../docs/agent/README.md) — общий workflow;
- [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md) — правила участия.
